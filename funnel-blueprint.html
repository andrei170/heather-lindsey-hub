Tech Stack (recommended, layered on existing)

  • Course host: Kartra (existing, keep it)
  • Landing pages: Custom HTML via Kartra page wrapper (Inner Circle), Kartra-native (homepage update)
  • Email: Kartra Sequences (existing - extend, do not replace)
  • Quiz / segmentation: Typeform for Inner Circle application
  • Payment: Kartra checkout (existing) for course tiers, Stripe for Inner Circle annual + retreat top-ups
  • Video host: YouTube unlisted (homepage VSL, fast load) or Wistia (control + analytics)
  • Analytics: GA4 + Meta Pixel + Microsoft Clarity (heatmaps for the new homepage)
  • Community (Inner Circle): Skool (preferred - low overhead) or private Discord channel
  • Scheduling: Calendly for Inner Circle intake call
  • Project / build: Notion (handover-friendly)

Integration Points

  1. Masterclass opt-in → Kartra tag "masterclass-registered" + state tag (live / replay / no-show)
  2. Kartra tag → Sequence trigger - 8-touch nurture starts T+0 from attendance state
  3. Level 1 purchase → suppress nurture, trigger course-onboarding sequence
  4. Bundle purchase → trigger 30-day bundle-graduate nurture toward Inner Circle waitlist
  5. Inner Circle Typeform submit → Calendly intake call + Heather email notification
  6. Money Meeting buyer → cross-sell tag, surface Inner Circle waitlist on completion
  7. Discord post-purchase → static pinned link to Inner Circle waitlist
  8. All conversion events → GA4 + Meta Pixel via GTM for full attribution

Owner Map

  • Heather: filming (homepage VSL recut session), Inner Circle intake calls, monthly group calls with the cohort, quarterly retreat content lead, top-line decisions on copy + brand
  • AG1: everything else - landing page build, email writing, Kartra automation setup, Discord pinned-post copy, content production cycles, ads management (Phase 4), weekly reporting

Failure Modes + Mitigations

  • Homepage VSL filming delays → recut existing masterclass footage as Phase 1 placeholder; replace with custom 4-7 min recording inside the first 30 days of go-live
  • Inner Circle cohort under-fills first round → seed founding cohort from bundle graduates + Discord regulars at a slightly reduced first-cohort rate to lock in case studies; raise to full price for cohort 2
  • Kartra sequence builder learning curve → AG1 builds and documents the 8-touch sequence in Kartra-native, hands over with a 30-min walkthrough recording
  • Quarterly retreat venue cost overrun → start with a single 2-day retreat at a hotel conference suite (low overhead) before scaling to full week-long destination retreats in Year 2

KPIs (90-day)

  • Phase 1 · Inner Circle landing live · 6-10 applications in first 30 days · 3-6 founding cohort members signed
  • Phase 1 · Homepage VSL live · cold-traffic-to-Level-1 conversion lift measured against 30-day baseline
  • Phase 1 · Speaker / author capture page live · appearance-night opt-in rate measured against the warm-audience baseline
  • Phase 2 · 8-touch masterclass nurture + 14-day speaker / author sequence live · masterclass-to-Level-1 conversion rate measured at day 14 and day 30
  • Phase 3 · 4-week pre-launch content live · Inner Circle waitlist target 50-80 signups
  • Phase 3 · YouTube + X + LinkedIn cadence live · monthly impressions + masterclass-opt-in rate tracked against the speaker / author capture sequence
  • Year-1 floor target · $330K-$640K incremental on top of existing course revenue (Install $290K-$520K + Recurring Engagement $40K-$120K)
